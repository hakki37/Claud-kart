# Claud-kart

Kart Kampanya Flutter uygulaması.

Bu sürümde:
- banka/kart logoları yatay ve yüksek kaliteli uzaktan logo kaynağıyla gösterilir,
- banka alanı boş gelen kampanyalarda güvenli banka çıkarımı yapılır,
- eski v20-v27 patch zinciri build'e dahil edilmez,
- Android APK GitHub Actions ile temiz olarak derlenir.
